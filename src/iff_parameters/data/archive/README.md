# Archive

These bundles are preserved for history but excluded from `list_bundles()` discovery.

They were the v0.1.0 seed: four ad-hoc snapshots of IFF force fields, ingested before the v0.2.0 rebuild established the `parameters/` vs `structures/` split and the canonical INTERFACE_FF_1_5 seed.

Do not reference from new structure entries. Use the canonical `parameters/cvff-interface/v1.5`, `parameters/pcff-interface/v1.5`, or `parameters/charmm27-interface/v1.5` instead.
